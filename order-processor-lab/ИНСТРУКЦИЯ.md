## Этап 3: «слепой» тест в Copilot (делается вручную в VS Code)

1. Откатить модель, чтобы агент создал её сам:
   ```powershell
   git switch -c blind-test before-blind-test
   ```
2. Открыть чат Copilot (`Ctrl+Alt+I`), новый диалог (`Ctrl+L` или `+`), режим **Agent**.
3. Отправить без слова «skill» и без `/`:
   > Создай в src/models.py модель возврата товара (RefundRequest) с полями order_id, reason (минимум 10 символов) и refund_amount (строго больше 0).
4. В логе чата проверить, что агент прочитал `SKILL.md` и `references/order_schema_v2.py`,
   а класс использует `ConfigDict`, `Field`, `@field_validator` + `@classmethod`, `Decimal`.
5. Если скилл не подхватился: проверить, что включена настройка `chat.useAgentSkills`
   (уже прописана в `.vscode/settings.json`), и повторить в **новом** чате.
6. Вернуться к готовому варианту: `git switch master`.

## Этап 4: проверка в терминале VS Code

```powershell
.\.venv\Scripts\Activate.ps1
ruff check .
pytest
```

Или вкладка **Testing** (колба слева) → Run All Tests.
